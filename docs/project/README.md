# heyjustin: project knowledge

What is specific to this product. Generic rules are in
[`../best-practices/`](../best-practices/README.md).

| File | Covers |
|---|---|
| [domain.md](domain.md) | What the product does, vocabulary, ticket lifecycle, modules |
| [decisions/](decisions/) | Why things are the way they are, one record per decision |
| [open-questions.md](open-questions.md) | Undecided points and known gaps, to settle before building on them |

A decision record is short: **context → decision → consequences**. When a
decision changes, write a new record that supersedes the old one instead of
rewriting history.
